# PenceAI: Personal Finance Assistant

## About This Project

PenceAI is a web-based personal finance assistant designed to help users manage their finances, track expenses, and make informed financial decisions using machine learning. The application is built with **Flask** and provides several key features accessible through a clean web interface.

The core of the project lies in its three machine learning models, which provide predictive insights into personal savings, stock market trends, and cryptocurrency prices.

-----

## Features

  * **Budget Advisor**: Predicts a user's recommended "desired saving" amount based on their total income and monthly payments (like rent or loans). It also calculates how many months it would take to reach a specific savings goal.
  * **Expenses Tracker**: A dashboard for users to log and visualize their daily expenses, helping them understand their spending habits.
  * **Stock & Crypto Predictions**: Utilizes time-series forecasting models to predict future prices for market assets:
      * **NVIDIA Stock Prediction**: Analyzes historical NVIDIA stock data to forecast future price movements.
      * **Bitcoin Price Prediction**: Uses an LSTM model to predict live Bitcoin prices based on recent trends.
  * **Saving Locks**: A feature that allows users to set up and manage specific savings goals (implied from `index.html` and `app.py`).

-----

## Models and Data

The project uses three distinct machine learning models trained on specific datasets.

### 1\. Budget Advisor (Linear Regression)

  * **Model**: This feature is powered by a **Linear Regression** model saved as `savings_model.pkl`. A `StandardScaler` (`savings_scaler.pkl`) is used to normalize the input features.
  * **Data**: The model was trained on the `data/data.csv` dataset.
  * **Features Used**: `IncomeTotal`, `MonthlyPayment`.
  * **Target Variable**: `desired_saving`.

### 2\. Stock Prediction (NVIDIA)

  * **Model**: While the `Stocks.ipynb` notebook explores data analysis, the predictive engine is designed as a time-series forecasting model (likely an LSTM, similar to the crypto model) to handle sequential stock data.
  * **Data**: The model uses historical stock data from `data/NVidia_stock_history.csv`.
  * **Features Used**: The data includes `Date`, `Open`, `High`, `Low`, `Close`, and `Volume`. The model would typically use a look-back window of these features to predict the next `Close` price.

### 3\. Cryptocurrency Prediction (Bitcoin)

  * **Model**: This prediction is generated by a **Long Short-Term Memory (LSTM)** neural network, a type of Recurrent Neural Network (RNN) well-suited for time-series forecasting. The model is built using Keras/TensorFlow.
  * **Data**: The model was trained on live Bitcoin data from `data/live_bitcoin.csv`.
  * **Features Used**: The model uses a look-back window (e.g., 60 time-steps) of `Price` and `Volume` to predict the future `Price`.

## How to Run

This is a Flask web application. To run it locally, follow these steps:

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/penceai/PenceAI.git
    cd PenceAI
    ```

2.  **Install dependencies:**
    It's recommended to use a virtual environment.

    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
    ```

    Install the required Python packages:

    ```bash
    pip install flask numpy pandas scikit-learn tensorflow
    ```

    *(Note: `yfinance` is also listed in one of the notebooks and may be required if you intend to fetch new stock data.)*

3.  **Run the application:**
    Ensure the trained models (`savings_model.pkl` and `savings_scaler.pkl`) are in the root directory.

    ```bash
    python app.py
    ```

4.  **Access the application:**
    Open your web browser and go to `http://127.0.0.1:5000` to use PenceAI.
